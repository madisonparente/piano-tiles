# piano-tiles
By Julianne Cifrodella, Mikayla Minton, and Madison Parente

# Expected Behavior
This project is a recreation of the app "Piano Tiles 2" using the NexysA7-100T FPGA board in SystemVerilog, run through Vivado. The "Piano Tiles 2" game consists of black tiles moving down the screen, running from top to bottom, and the user is in charge of pressing them before they reach the bottom; the longer you play the game, the more advanced and faster it runs. Our recreation features sound output based on the song played, the score is shown on the LED display, and the user can play the game using the buttons on the NexysA7 board.
